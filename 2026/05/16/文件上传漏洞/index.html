什么是文件上传

  • 文件上传漏洞是指由于程序员在对用户文件上传部分的控制不足或者处理缺陷，而导致的用户可以越过其本身权限向服务器上上传可执行的动态脚本文件。这里上传的文件可以是木马，病毒，恶意脚本或者WebShell等。“文件上传”本身没有问题，有问题的是文件上传后，服务器怎么处理、解释文件。如果服务器的处理逻辑做的不够安全，则会导致严重的后果。

什么是webshell

  • WebShell就是以asp、php、jsp或者cgi等网页文件形式存在的一种命令执行环境，也可以将其称之为一种网页后门。攻击者在入侵了一个网站后，通常会将这些asp或php后门文件与网站服务器web目录下正常的网页文件混在一起，然后使用浏览器来访问这些后门，得到一个命令执行环境，以达到控制网站服务器的目的（可以上传下载或者修改文件，操作数据库，执行任意命令等）。 WebShell后门隐蔽较性高，可以轻松穿越防火墙，访问WebShell时不会留下系统日志，只会在网站的web日志中留下一些数据提交记录

第五关前置知识

  • .htaccess: 分布式配置文件,一般用于url重写,认证,访问控制等
    • 作用范围: 特定目录(一般是网站根目录)及其子目录
    • 优先级: 较高, 可覆盖apache的主要配置文件(httpd-conf)
    • 生效方式: 修改后立刻生效
  • httpd-conf
    • 作用: 包含apachehttp服务器的全局行为和默认设置
    • 作用范围:整个服务器
    • 优先级:较低
    • 生效方式; 管理员权限,重启服务器后生效
  • .user.ini
    • 作用:特定于用户或特定目录的配置文件,通常位于web应用程序的根目录下
    • 它用于覆盖或追加全局配置文件(如php.ini)中的php配置选项
    • 作用范围: 存放该文件的目录以及子目录
    • 优先级: 较高,可以覆盖php.ini
    • 生效方式:立即生效
  • php.ini
    • 作用: 存储了对整个php环境生效的配置选项,它通常位于php安装目录中
    • 作用范围:所有运行在该php环境中的php请求
    • 优先级: 较低
    • 生效方式: 重启php或web服务器

pass-9

前置知识

  • 额外数据流: 数据流是一种用于在文件内部存储额外数据的机制,你直接打开文件是打开的默认数据流,而额外数据流你直接打开看不见,但是他会"寄生"在宿主文件身上.我们可以通过在文件名后面添加::$DATA来访问它
  • 可以用cmd来写入访问额外数据流
    • 比如说写入"hello" 在该目录的cmd中输入echo "hello" >>1.txt:nihao nihao是额外数据流的空间名字
    • 在当前目录中输入notepad 1.txt 此时是用记事本打开1.txt文件,如果输入notepad 1.txt:nihao则会用记事本打开额外数据流的内容
  • 写入方式:
    • echo: echo 内容 >>文件名:数据流名将写的内容输入到额外数据流中
    • type: type 2.txt >> 1.txt:nihao 将2.txt的内容写进1.txt的额外数据流之中
  • 查看方法:
    • notepad 文件名: 数据流名
  • 在php中,文件的附加数据流是不会验证后缀的,仅表示数据流而不是文件

步骤

  • 查看源码,相对比发现没有禁用::DATA数据流
  • 随便写入一个内容到木马的额外数据流里面,抓包在文件拓展名后面加上::&DATA.
  • 上传成功后打开文件网址,将::DATA去掉,测试连接

pass-12(get请求获得路径,get是用url传递的参数)

前置知识(在5.3以下的版本使用%00截断效果明显,版本过高可能使用不了)

  • 空字符: 在老版本的php(等计算机语言),当发现空字符时,不会读取后续内容
  • 0x00: 在编程语言中使用
  • %00: 在url编码中使用
  • 前提:
    • PHP版本必须低于5.3.4，且magic_quotes_gpc需关闭。
    • 高版本PHP（如5.4.45及以上）已修复此漏洞，不再受%00截断影响。

步骤(在php.ini里面找到magic_quotes_gpc,将On改为Off,再重启小皮)

  • 先分析,白名单,有临时路径和真实路径的参与,先上传白名单允许的文件拓展名
  • 再抓包,在upload/(页面顶部)后面加上111.php文件(将文件用php格式保存),最后在后面添加%00把后续内容截断.
  • 测试连接

pass-14

前置知识

  • 图片字节标识
    • JPEG/JFIF(常见的照片格式): 头两个字节为 0xFF 0xD8
    • PNG(无损压缩格式): 头两个字节为 0x89 0x50
    • GIF(支持动漫的图像格式): 头两个字节为 0x47 0x49
    • BMP(windows位图格式): 头两个字节为 0x42 0x4D
    • TIFF(标签图像文件格式): 头两个字节可以是不同的数值
  • 字节是计算机中存储和传输数据的基本单位,通常表示为一个八位(8-bit)的二进制数字序列.
  • utf-8中,一个英文字符占一个字节,中文(含繁体字)占三个字节

步骤

  • 检查源代码,发现白名单,并且验证方法是打开文件的前两个字节判断
  • 将一句话木马的字节标识符改为白名单所允许的格式(该题检验文件拓展名的方式是检验文件头两个字节)
  • 再利用文件包含漏洞运行木马的php,从而达到入侵的目的
    • 发现文件包含漏洞: 新版本的php在旧版本的php基础上修改,所以会引用旧版本的文件.如果没有做文件过滤的话,我们就可以通过文件包含找到漏洞,从而上传文件,该文件是以php的形式解析,所以可以使得木马成功入侵
  • 文件包含漏洞会以php方式解析,此时我们知道他是用get传参,只需要?file=upload/文件名,替换掉file文件并以php的形式解析木马(upload是存放文件的文件夹)
  • 测试连接
